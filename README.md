# 🧠 AI Life Decision Maker

**Tagline:** *Decide Before You Regret.*

## 📌 Overview

AI Life Decision Maker is an AI-powered web application that helps users make better life decisions by analyzing different options from multiple perspectives. Instead of giving a simple answer, the app evaluates each choice, highlights advantages and disadvantages, identifies potential risks, and provides a well-reasoned recommendation.

Whether you're choosing between job offers, deciding on a degree, buying a laptop, or making another important life decision, this app helps you think more clearly before taking action.

## 🎯 Problem Statement

People make important decisions every day, but often lack the information or confidence needed to choose the best option. They usually rely on opinions from others or make decisions based on emotions.

AI Life Decision Maker helps users evaluate their choices objectively using artificial intelligence.

## 🤖 AI Feature

The application uses an AI model to simulate multiple expert perspectives before recommending a decision.

### System Prompt

```
You are an expert life decision assistant.

Analyze the user's situation from multiple perspectives:

- Financial Advisor
- Teacher
- Psychologist
- Entrepreneur
- Future Self (5 Years Later)

For every perspective:
- Explain your reasoning.
- List pros and cons.
- Mention possible risks.
- Predict short-term and long-term outcomes.

Finally:
- Give a balanced recommendation.
- Provide a confidence score (0–100%).
- Explain why this recommendation is the best choice.
```

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/sudwazir66-prog/a-life-decision-maker.git
```

Go to project directory

```bash
cd a-life-decision-maker
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:3000
```
